# Known Issues

Base de conhecimento para registro de falhas, causas e soluções encontradas durante o desenvolvimento.

## Objetivo

Centralizar problemas atípicos encontrados pelos times de desenvolvimento e permitir que outras pessoas encontrem rapidamente a solução.

## Estrutura de um registro

Cada problema deve conter:

- Identificação do problema
- Ambiente afetado
- Sintoma
- Mensagem de erro
- Causa raiz
- Solução aplicada
- Workaround (quando existir)
- Tags para busca

## Categorias

- Esteiras
- AWS
- GitHub
- StackSpot
- Terraform
- Spark
- Banco de dados

## Como contribuir

Utilize o arquivo `TEMPLATE.md` para criar novos registros.

Exemplo:

```
docs/esteira/EST-001-nome-do-problema.md
```
